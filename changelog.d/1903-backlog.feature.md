- Added `CAPTCHA_PROVIDER` (`builtin`, `recaptcha`, `turnstile`) in configuration and Admin UI settings; when an external provider is selected, the built-in CAPTCHA endpoints are disabled (`404`) and the Escalation Engine verifies against Google reCAPTCHA or Cloudflare Turnstile (`siteverify`).
- Added visitor-selectable accessible question types (`math`, `color`, `word`) and browser `speechSynthesis` read-aloud support to the built-in CAPTCHA, sharing all one-attempt, rate-limit, minimum-solve-time, and client-proof protections.
- Added an off-by-default manual access request path (`CAPTCHA_MANUAL_REQUESTS_ENABLED=false`) with per-IP cooldown, one-pending-per-IP, global queue and rate caps, Admin UI approve/deny controls (HTML-escaped notes, 24h temporary IP allowlist), and an opt-in Cloudflare "Under Attack" mode suggestion banner (`CLOUDFLARE_ENABLED`).
