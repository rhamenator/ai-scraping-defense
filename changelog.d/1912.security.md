The PostgreSQL and Redis password files (and the `secrets/` directory) are no longer world-readable on the host (part of #1912). They were mode 0644 in a 0755 directory because the non-root containers read them through a bind mount. A new one-shot `secrets_init` service in `docker-compose.yaml` (root, no network, three capabilities, read-only root) copies `./secrets` into a `runtime_secrets` volume that only Docker can reach, and every service that read `./secrets` now mounts that volume and waits for the job. The Linux and macOS generators now create the directory 0700 and the files 0600 under `umask 077`. Existing installs: re-run `docker compose up`; `chmod 700 secrets && chmod 600 secrets/*.txt` on the host tightens existing files. The `grafana_admin_password.txt` file is unaffected (Grafana bind-mounts that single file directly).
